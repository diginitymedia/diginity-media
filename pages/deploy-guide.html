No terminal needed — drag and drop in the browser

📦
First, unzip diginity-media.zip on your computer. You'll get a folder called diginity-media/ containing index.html, pages/, assets/, and the other files.
1
On your empty GitHub repo page, click "uploading an existing file" (the link in the middle of the page)

Open the unzipped diginity-media/ folder on your computer, select all files inside it (Ctrl+A / Cmd+A), and drag them into the GitHub upload box

🔧 Common issues & fixes

Site deploys but shows blank page

Check that index.html is at the root of your repo (not inside a subfolder). GitHub repo should show index.html as the first file, not a diginity-media/ folder.

Inner pages / navigation not working on Netlify

This shouldn't happen since the site uses hash-based routing — but if it does, check that netlify.toml was uploaded and appears in your repo.

Contact form submissions not appearing

Go to Netlify → Forms — the form needs at least one real submission to appear. Submit a test entry on your live site, then check the Forms tab.

GitHub upload getting stuck / timing out

GitHub has a file-count limit for browser uploads. Upload in batches: first index.html + root files, then commit; then upload the pages/ folder and commit separately.

Want to add a real domain later (e.g. diginity.in)?

Buy the domain from GoDaddy or Namecheap → Netlify dashboard → Domain management → Add custom domain → follow the nameserver instructions. HTTPS is automatically provisioned, free.
