EmailJS — Instant Email Alerts FREE

Get an email to your inbox the moment someone submits the contact form — no backend needed

💡
EmailJS lets your website send emails directly from the browser — no server required. Free plan: 200 emails/month. That's 200 leads/month for free.
1

Create a free EmailJS account

Go to emailjs.com → Sign up free → Verify your email

2

Add an Email Service

Dashboard → Email Services → Add New Service → Choose Gmail → Connect your Gmail account → Copy the Service ID

Example Service ID
service_abc123   ← copy this
3

Create an Email Template

Dashboard → Email Templates → Create New → paste this template:

EmailJS Template (paste into Subject field)
Subject: 🎯 New Lead from {{from_name}} — {{services}}

New lead from Diginity Media website:

Name:     {{from_name}}
Phone:    {{phone}}
Email:    {{from_email}}
Company:  {{company}}
Services: {{services}}
Budget:   {{budget}}
Source:   {{source}}
Message:  {{message}}
Time:     {{timestamp}}

Reply to: {{reply_to}}

Copy the Template ID (e.g. template_xyz789)

4

Get your Public Key

Dashboard → Account → General → Public Key → copy it

5

Add keys to index.html

Open index.html → Ctrl+F for YOUR_EMAILJS_PUBLIC_KEY → replace all 3 values:

index.html — find and replace these 3 values
// Line 1 — in the <head> script:
emailjs.init("YOUR_EMAILJS_PUBLIC_KEY");
// Replace with:
emailjs.init("user_AbCdEfGhIjKlMnOp");

// Line 2 — in the submitForm function:
emailjs.send('YOUR_SERVICE_ID', 'YOUR_TEMPLATE_ID', ...
// Replace with:
emailjs.send('service_abc123', 'template_xyz789', ...
✅
Test it: Submit the contact form on your site → check your Gmail inbox within 10 seconds. If it arrives, EmailJS is working.

Deploy to Netlify FREE

Get a live URL in 60 seconds — HTTPS, CDN, and Netlify Forms all included

🚀
Netlify's free tier is unlimited bandwidth for static sites. It also handles your contact form submissions and stores them in a dashboard — no backend needed.
1

Prepare your folder

Make sure all files are in one folder. Rename the main file to index.html

Your folder structure
diginity-media/
├── index.html              ← main website (renamed)
├── netlify.toml            ← deployment config
├── sitemap.xml
├── robots.txt
├── manifest.json
├── diginity-media-logo.svg
├── diginity-case-studies.html
├── diginity-pricing-calculator.html
├── diginity-lead-dashboard.html
├── diginity-blog-*.html    ← all blog files
├── diginity-404.html
├── diginity-privacy-policy.html
└── diginity-terms.html
2

Go to netlify.com and sign up

Sign up free with Google → you'll see a dashboard with a big drag-and-drop zone

3

Drag & drop your folder

Drag the entire diginity-media/ folder into the Netlify drop zone → it deploys in ~20 seconds → you get a URL like amazing-einstein-a1b2c3.netlify.app

4

Enable Netlify Forms (to receive leads in dashboard)

Site → Settings → Forms → Enable form detection → Your contact form submissions now appear in Site → Forms → diginity-leads

5

Set up form email notifications

Site → Forms → diginity-leads → Notifications → Add notification → Email → enter your email → Save
Now you get an email every time someone submits the form ✅

Node.js Backend OPTIONAL — Advanced

For persistent lead storage, CRM integration, and custom APIs — deploy free on Railway

⚠️
Do Netlify Forms + EmailJS first. This backend is only needed if you want to store 1000s of leads in a database, build a CRM, or connect APIs. Skip for now if you're just getting started.
1

Install Node.js on your computer

Download from nodejs.org → LTS version → install

2

Set up the backend folder

Terminal commands
# Navigate to your project
cd diginity-media/backend

# Install dependencies
npm install

# Copy environment file
cp .env.example .env

# Edit .env with your real values (Gmail, WhatsApp number)
# Then start the server
npm start

# Visit http://localhost:3000/api/health
# You should see: {"ok":true}
3

Configure Gmail App Password

Regular Gmail password won't work. You need an App Password:

  1. Go to myaccount.google.com/security
  2. Enable 2-Step Verification (required)
  3. Search "App Passwords" → Create → name it "Diginity Backend"
  4. Copy the 16-character password → paste into .env as SMTP_PASS
4

Deploy to Railway (free)

Deploy steps
# 1. Push backend to GitHub
cd backend
git init
git add .
git commit -m "Diginity Media backend"
git remote add origin https://github.com/yourusername/diginity-backend.git
git push -u origin main

# 2. Go to railway.app → New Project → Deploy from GitHub
# 3. Select your repo → Railway auto-detects Node.js
# 4. Add environment variables in Railway dashboard
# 5. Railway gives you a URL: diginity-backend.up.railway.app
5

Connect frontend to your backend URL

In index.html, Ctrl+F for BACKEND_URL → replace with your Railway URL:

index.html
// Find this in the form submit handler:
const BACKEND = 'https://diginity-backend.up.railway.app';

// Then the fetch call sends to:
fetch(BACKEND + '/api/contact', { method:'POST', ... })

Google Analytics 4 FREE

See exactly who visits your site, which pages convert, and where traffic comes from

1

Create a GA4 property

Go to analytics.google.com → Admin → Create Property → name: "Diginity Media" → India → INR → Business website → Create

2

Get your Measurement ID

Property → Data Streams → Add stream → Web → enter https://diginity.in → Copy Measurement ID (starts with G-)

3

Add to index.html

Ctrl+F for G-REPLACE-WITH-YOUR-GA4-ID → replace with your actual ID in both places:

Find & replace in index.html
// Before:
'G-REPLACE-WITH-YOUR-GA4-ID'

// After (your real ID):
'G-AB12CD34EF'
6

Google Search Console FREE

Tell Google your site exists — required for SEO ranking

1

Add your property

Go to search.google.com/search-console → Add property → URL prefix → enter https://diginity.in

2

Verify ownership (HTML tag method)

Choose "HTML tag" → copy the meta tag → paste it into index.html inside <head> → redeploy to Netlify → click Verify

Paste this in <head> of index.html
<meta name="google-site-verification" content="YOUR_CODE_HERE"/>
3

Submit sitemap

Search Console → Sitemaps → enter sitemap.xml → Submit
Google will now crawl and index all your pages ✅

4

Request indexing for your homepage

URL Inspection → enter https://diginity.in → Request Indexing → Google will index it within hours
